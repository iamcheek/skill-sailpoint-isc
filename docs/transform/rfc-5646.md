# RFC5646

**Transform type:** `"rfc5646"`

The RFC5646 transform converts incoming strings into RFC 5646 language tag values. It accepts either recognized language names (optionally with a country/region qualifier) or three-letter language abbreviations and outputs the standardized language tag.

## Attributes

| Attribute | Required | Type | Description |
|---|---|---|---|
| `input` | No | object | Explicitly defines the input data passed into the transform; if omitted, uses the source and attribute configuration from the UI. |

Top-level (outside `attributes`):

| Property | Required | Type | Description |
|---|---|---|---|
| `type` | Yes | string | Must be set to `rfc5646`. |
| `name` | Yes | string | Display name for the transform in UI dropdowns. |
| `requiresPeriodicRefresh` | No | boolean | Whether to reevaluate during identity refresh. Default: `false`. |

### Accepted input forms

- Three-letter language abbreviations (e.g. `SPA`)
- Language names (e.g. `Spanish`)
- Language names with a country/region qualifier (e.g. `Spanish (Spain)`)

Returns `null` if the input is not a valid country code or language name.

## Example(s)

Basic configuration:
```json
{
  "type": "rfc5646",
  "name": "RFC5646 Transform"
}
```

Example transformation — input `Spanish` → output `es`.
