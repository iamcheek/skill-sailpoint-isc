# ISO3166

**Transform type:** `"iso3166"`

Converts incoming string data into an ISO 3166 country code value. Accepts multiple input formats — country names (English or native), alpha2 codes, alpha3 codes, or numeric codes — and outputs the country identifier in a specified format.

## Attributes

| Attribute | Required | Type | Description |
|---|---|---|---|
| `format` | No | string | Output format specification. Allowed values: `alpha2` (two-character code, e.g. `"US"`; this is the default), `alpha3` (three-character code, e.g. `"USA"`), `numeric` (numeric code, e.g. `"840"`). |
| `input` | No | object | Explicitly defines the input data; if omitted, uses the source/attribute combination from the UI. |

Top-level transform properties (outside the `attributes` object):

| Property | Required | Type | Description |
|---|---|---|---|
| `type` | Yes | string | Must be `iso3166`. |
| `name` | Yes | string | Display name for the transform in UI dropdown menus. |
| `requiresPeriodicRefresh` | No | boolean | Whether to reevaluate transform logic during nightly identity refresh. Default: `false`. |

### Accepted input values

- Alpha2 codes (e.g. `"ES"`)
- Alpha3 codes (e.g. `"ESP"`)
- Numeric codes (e.g. `724`)
- English country names (e.g. `"United States of America"`)
- Native country names (e.g. `"España"`)

## Example(s)

Default alpha2 format — input `"United States of America"` → output `"US"`:
```json
{
  "type": "iso3166",
  "name": "ISO3166 Transform"
}
```

Numeric format — input `"ES"` → output `"724"`:
```json
{
  "attributes": {
    "format": "numeric"
  },
  "type": "iso3166",
  "name": "ISO3166 Transform"
}
```

## Notes

- Invalid country codes or unrecognized country names return `null`.
- Default output format is `alpha2` if the `format` attribute is not specified.
